# Esercizio 1 — Invio di notifiche

**Tempo indicativo: 5–7 minuti · Java 25**

Un canale di notifica invia un testo. Per semplicità, l’implementazione mostrata stampa invece di inviare realmente. I testi sono non nulli.

Le istruzioni dopo le dichiarazioni sono eseguite in un metodo statico separato. I numeri di riga non fanno parte del codice.

```java
01  interface Notifier {
02      void send(String text);
03  }
04  class Email implements Notifier {
05      public void send(String text) {
06          System.out.println("EMAIL: " + text);
07      }
08  }
```

```java
09  Notifier channel = new Email();
10  channel.send("Alert");
```

## 1. Scelta multipla

Che cosa accade eseguendo le righe 9–10? Seleziona una sola risposta.

- **A.** Non compila: un’interfaccia non può essere il tipo di una variabile.
- **B.** Stampa `EMAIL: Alert`.
- **C.** Non compila: `Notifier` non fornisce un corpo per `send`.
- **D.** Compila, ma solleva `ClassCastException` alla riga 10.

## 2. Risposta aperta

Si vuole introdurre una famiglia di canali con un prefisso non nullo diverso per ogni istanza. Tutti devono applicare la stessa procedura: anteporre il prefisso al messaggio e affidare l’invio effettivo alla specifica implementazione. Il codice che usa `Notifier` non deve cambiare.

Scegli una struttura che riusi questa procedura senza duplicarla tra i canali. Indica tipo e relazioni della nuova dichiarazione, stato necessario e firme dei metodi, distinguendo quelli implementati da quelli lasciati alle implementazioni concrete. Non scrivere corpi o canali concreti.

**Lunghezza indicativa:** uno schema di massimo 6 righe e una frase di motivazione. Sono ammesse strutture alternative che rispettino i requisiti.

# Esercizio 2 — Etichette dei componenti

**Tempo indicativo: 5–7 minuti · Java 25**

I componenti espongono un’etichetta attraverso un’interfaccia. Il codice mostrato definisce una delle implementazioni utilizzate dall’applicazione.

Le istruzioni dopo le dichiarazioni sono eseguite in un metodo statico separato. I numeri di riga non fanno parte del codice.

```java
01  interface Named {
02      default String label() { return "generic"; }
03  }
04  class Tag implements Named {
05      @Override public String label() { return "tag"; }
06  }
```

```java
07  Named component = new Tag();
08  System.out.println(component.label());
```

## 1. Scelta multipla

Che cosa accade eseguendo le righe 7–8? Seleziona una sola risposta.

- **A.** Stampa `generic`, perché il riferimento ha tipo `Named`.
- **B.** Non compila: un metodo `default` non può essere ridefinito.
- **C.** Stampa `tag`.
- **D.** Stampa prima `generic` e poi `tag`.

## 2. Risposta breve

In una versione distinta si elimina il metodo `label` da `Tag` e si modifica la sua dichiarazione in `class Tag implements Named, Audited`, aggiungendo questa interfaccia non imparentata con `Named`:

```java
09  interface Audited {
10      default String label() { return "audit"; }
11  }
```

Valuta la compilazione della nuova versione. Se necessario, indica la modifica minima a `Tag` per fare in modo che usi il comportamento definito da `Named`, senza cambiare le interfacce.

**Lunghezza indicativa:** 1–2 frasi e massimo 3 righe di codice.

# Esercizio 3 — Costo di un piano

**Tempo indicativo: 5–7 minuti · Java 25**

Ogni piano calcola un costo da una quota fissa e una parte variabile. Il numero di unità deve essere non negativo; un valore negativo deve essere rifiutato con `IllegalArgumentException`. Le sottoclassi ricevono soltanto unità valide in `extra`. I valori sono piccoli e non producono overflow.

Le istruzioni dopo le classi sono eseguite in un metodo statico separato. I numeri di riga non fanno parte del codice.

```java
01  abstract class Plan {
02      private final int base;
03      Plan(int base) { this.base = base; }
04      public final int total(int units) {
05          if (units < 0) throw new IllegalArgumentException();
06          return base + extra(units);
07      }
08      protected abstract int extra(int units);
09  }
10  class Metered extends Plan {
11      Metered() { super(2); }
12      @Override protected int extra(int units) { return 3 * units; }
13  }
```

```java
14  Plan plan = new Metered();
15  System.out.println(plan.total(4));
```

## 1. Scelta multipla

Che cosa accade eseguendo le righe 14–15? Seleziona una sola risposta.

- **A.** Stampa `14`.
- **B.** Stampa `12`.
- **C.** Stampa `2`.
- **D.** Non compila perché `Plan` è astratta.

## 2. Risposta breve

Un revisore propone una sottoclasse gratuita che ridefinisca `public int total(int units)` restituendo sempre zero. La proposta è compilabile? Descrivi come definire invece una sottoclasse gratuita per tutte le unità valide, conservando il controllo condiviso sui valori negativi.

**Lunghezza indicativa:** 2–3 frasi, indicando la chiamata al costruttore della superclasse e il metodo da implementare; non occorre una classe completa.
