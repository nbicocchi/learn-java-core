# Esercizio 6 — Invio di notifiche

**Tempo indicativo: 5–7 minuti · Java 25**

Un canale di notifica invia un testo. Per semplicità, l’implementazione mostrata stampa invece di inviare realmente. I testi sono non nulli.

Le istruzioni dopo le dichiarazioni sono eseguite in un metodo statico separato. I numeri di riga non fanno parte del codice.

```java
01  interface Notifier {
02      void send(String text);
03  }
04  class Email implements Notifier {
05      public void send(String text) {
06          System.out.println("EMAIL: " + text);
07      }
08  }
```

```java
09  Notifier channel = new Email();
10  channel.send("Alert");
```

## 1. Scelta multipla

Che cosa accade eseguendo le righe 9–10? Seleziona una sola risposta.

- **A.** Non compila: un’interfaccia non può essere il tipo di una variabile.
- **B.** Stampa `EMAIL: Alert`.
- **C.** Non compila: `Notifier` non fornisce un corpo per `send`.
- **D.** Compila, ma solleva `ClassCastException` alla riga 10.

## 2. Risposta aperta

Si vuole introdurre una famiglia di canali con un prefisso non nullo diverso per ogni istanza. Tutti devono applicare la stessa procedura: anteporre il prefisso al messaggio e affidare l’invio effettivo alla specifica implementazione. Il codice che usa `Notifier` non deve cambiare.

Scegli una struttura che riusi questa procedura senza duplicarla tra i canali. Indica tipo e relazioni della nuova dichiarazione, stato necessario e firme dei metodi, distinguendo quelli implementati da quelli lasciati alle implementazioni concrete. Non scrivere corpi o canali concreti.

**Lunghezza indicativa:** uno schema di massimo 6 righe e una frase di motivazione. Sono ammesse strutture alternative che rispettino i requisiti.
