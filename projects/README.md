## Project requirements

- Develop the project **individually**, using **Java**, **Maven** for build and dependency management, and **AI-assisted coding tools**.
- Include a `README.md` describing the project goals, design decisions, internal structure, prerequisites, and **exact startup instructions**. Provide either a launcher or an explicitly documented Maven command, including any required build or setup steps.
- Include a `LICENSE` file specifying the project's license.
- Document how to use the application and its main features.
- Ensure cross-platform support: **the instructor will run the project on Linux**. Avoid machine-specific absolute paths and hard-coded path separators; respect filename case and include all required resources.

Take inspiration from the examples above and the [JavaFX course examples](https://github.com/nbicocchi/learn-java-javafx/tree/main/code). Appropriate external libraries are encouraged to promote code reuse and modularity.

## Exam submission

Publish your project in a **public GitHub repository** and submit its URL to the instructor **before the exam** through the [project submission form](https://docs.google.com/forms/d/e/1FAIpQLSeNDcHf6t4hLVJFgaQgIYuyHf9RBsqFUl9wXsMIVWy4_-a4QA/viewform?usp=dialog).

**Submitting the repository URL in advance is a requirement for admission to the exam.**

## Assessment

The project is assessed as a working application, based on:

| Criterion | Expectations |
|---|---|
| **Reproducible startup** | The application starts on Linux using the launcher or Maven command documented in the README. |
| **Working functionality** | The main features work without crashes or blocking issues during normal use. |
| **Presentation and usability** | The interface is visually coherent and easy to understand, with clear instructions, messages, and interaction flow. A text-based interface is also acceptable if well presented and usable. |

The assessment focuses on the application **as seen and used**, not on a source-code review. Individual technical knowledge is assessed through the written exam.
