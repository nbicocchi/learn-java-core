# Labs

[← Java Core](../README.md)

These incremental labs guide us through building a complete Java application together in class, from the desktop frontend to the backend and database. Follow them in order.

## Learning path

| Lab | Topic | Material |
|---|---|---|
| 1 | JavaFX interface | [Theory](lab1/theory.md) · [Tutorial](lab1/tutorial.md) |
| 2 | JDBC concepts, Docker, and PostgreSQL CLI | [Theory](lab2/theory.md) · [Tutorial](lab2/tutorial.md) |
| 3 | Persistent JavaFX address book with JDBC | [Theory](lab3/theory.md) · [Tutorial](lab3/tutorial.md) |
| 4 | Spring Boot REST backend | [Theory, runnable example, and curl requests](lab4/theory.md) |
| 5 | JavaFX REST client for the lab4 backend | [Theory](lab5/theory.md) · [Tutorial](lab5/tutorial.md) |

## Getting started

- Install JDK 25 and Maven, plus the tools required by the lab you are following.
- Use the theory pages for concepts and the tutorials for guided implementation and startup commands.
- Follow each lab's database and service setup instructions before running its application.
- For lab5, start the **lab4 backend** first: lab5 is a REST client, not a standalone backend.

See the [course software list](../README.md#software) for tool download links. Labs are not included in the course PDFs.
