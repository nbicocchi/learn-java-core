# Java Arrays

In Java, an array is an object that can store a **fixed-size sequence of elements of the same data type**.

* **An array is an object**, which means it can be assigned to a variable, passed as a parameter to a method, and returned as a value from a method.
* **Arrays are zero-indexed**, which means that the first element in an array has an index of `0`, the second element has an index of `1`, and so on.
* **The length of an array is fixed** when it is created and cannot be changed later. Elements can be modified, but elements cannot be added or removed.
* **Arrays can store elements of any data type**, including primitive types such as `int`, `double`, and `boolean`, as well as reference types such as `String` and `Integer`.
* **Arrays can be multidimensional**. In Java, a multidimensional array is an array whose elements are themselves arrays.

## Creating an array

### Declaration

```java
int[] numbers;

String[] names;
```

### Declaration and initialization with default values

```java
int[] numbers = new int[5]; // all zeros

String[] names = new String[4]; // all references with null values
```

When an array is created with `new`, its elements are automatically initialized with their default values:

* numeric primitive types → `0` (or `0.0`)
* `boolean` → `false`
* `char` → `'\u0000'`
* reference types → `null`

### Declaration and initialization with custom values

```java
int[] numbers = {1, 2, 3, 4, 5};

String[] names = {"John", "Mary", "David", "Sarah"};
```

### Declaration and initialization in two statements

When declaration and initialization are performed in separate statements, the `new` expression must be used:

```java
int[] numbers;
numbers = new int[]{1, 2, 3, 4, 5};

String[] names;
names = new String[]{"John", "Mary", "David", "Sarah"};
```

## Arrays in memory

![](images/basics-array-example-primitive-types.avif)

![](images/basics-array-example-object-reference.avif)

An array is an object, so the array itself is stored as an object managed by the JVM.

For an array of primitive types, the array contains the actual primitive values.

For an array of reference types, the array contains references to objects. The objects themselves are separate objects.

For example:

```java
int[] numbers = {1, 2, 3};

String[] names = {"Alice", "Bob", "Carol"};
```

`numbers` contains the integer values directly, while `names` contains references to `String` objects.

## Multi-Dimensional arrays

In Java, you can create multidimensional arrays with two or more dimensions. A two-dimensional array is an **array of arrays**.

This example declares a two-dimensional array of `String` named `table` with 2 rows and 3 columns.

```java
String[][] table = new String[2][3];
table[0][2] = "Mary";
```

![](images/basics-multidimensional-arrays.avif)

> **NOTE:** Rows in multidimensional arrays are separate array objects. A two-dimensional array in Java is therefore not necessarily a single contiguous block of elements in memory. Switching rows is an extremely fast operation because it only requires changing references to the row arrays.

For example:

```java
String[][] table = {
    {"Alice", "Bob", "Carol"},
    {"Dave", "Eve", "Frank"}
};

// Swap rows
String[] temp = table[0];
table[0] = table[1];
table[1] = temp;
```

In this case, no `String` objects are copied. We are only swapping references to the row arrays.

After the swap:

* `table[0]` refers to `{"Dave", "Eve", "Frank"}`
* `table[1]` refers to `{"Alice", "Bob", "Carol"}`

The operation runs in **constant time, O(1)**, because it only reassigns two references rather than copying the individual elements.

---

This other example declares a two-dimensional array of `int` named `matrix`.

```java
int[][] matrix; // only declared
```

```java
matrix = new int[3][4]; // declared and created empty
```

```java
int[][] matrix = {{1, 2}, {3, 4}, {5, 6}}; // declared, created and filled
```

## Assigning and accessing elements

An element of an array is referred to by its **index**.

The index is an integer, and its value must satisfy:

```text
0 <= index < array.length
```

For example, an array that holds 5 elements has indices `0`, `1`, `2`, `3`, and `4`.

```java
import java.util.Arrays;

public static void main(String[] args) {
    int[] numbers = new int[5];

    numbers[0] = 42;
    numbers[1] = 13;
    numbers[2] = 12;
    numbers[3] = 7;
    numbers[4] = 1;

    System.out.println(Arrays.toString(numbers));
}
```

The output is:

```text
[42, 13, 12, 7, 1]
```

## Iterating over an array

You can find the size of an array through its associated field `length`.

> **NOTE:** `length` is a field, not a method call, so `numbers.length()` doesn't work. The correct syntax is `numbers.length`.

You can iterate over an array in various ways.

### Using a `while` loop

```java
public static void main(String[] args) {
    int[] numbers = new int[4];

    int index = 0;

    while (index < numbers.length) {
        System.out.println(numbers[index]);
        index = index + 1;
    }
}
```

### Using a `for` loop

```java
public static void main(String[] args) {
    int[] numbers = new int[4];

    for (int index = 0; index < numbers.length; index++) {
        System.out.println(numbers[index]);
    }
}
```

### Using an enhanced `for` loop

```java
public static void main(String[] args) {
    int[] numbers = new int[4];

    for (int number : numbers) {
        System.out.println(number);
    }
}
```

The enhanced `for` loop is useful when we need to access every element but do not need its index.

If the index is outside the valid range of the array, an **`ArrayIndexOutOfBoundsException`** is thrown.

```java
public static void main(String[] args) {
    int[] numbers = new int[4];

    // ArrayIndexOutOfBoundsException
    System.out.println(numbers[4]);
}
```

The valid indices for an array of length `4` are `0`, `1`, `2`, and `3`.

The next example is a program that fills an array with user-specified numbers and prints them back.

```java
import java.util.Scanner;

public static void fillArray() {
    Scanner reader = new Scanner(System.in);

    System.out.print("How many numbers? ");
    int howMany = reader.nextInt();

    int[] numbers = new int[howMany];

    System.out.println("Enter the numbers:");

    for (int i = 0; i < numbers.length; i++) {
        numbers[i] = reader.nextInt();
    }

    System.out.println("Here are the numbers again:");

    for (int i = 0; i < numbers.length; i++) {
        System.out.println(numbers[i]);
    }
}
```

## Passing arrays to methods

You can use arrays as method parameters just like any other reference type.

When you use an array as a parameter of a method, **the method receives a copy of the reference to the array**.

Java is always **pass-by-value**. In this case, the value being copied is the reference to the array, not the array itself.

```java
public class Main {
    public static void listElements(int[] integerArray) {
        for (int n : integerArray) {
            System.out.printf("%d ", n);
        }

        System.out.println();
    }

    public static void main(String[] args) {
        int[] numbers = {1, 2, 3};

        listElements(numbers);

        listElements(new int[]{1, 2, 3});
    }
}
```

Both calls work because an array reference can be passed as a method argument.

> **NOTE:** Arrays are objects, so when a method modifies an element of an array, the modification is visible after the method returns because the caller and the method refer to the same array object.

```java
import java.util.Arrays;

public class Main {
    public static void addOne(int[] integerArray) {
        for (int i = 0; i < integerArray.length; i++) {
            integerArray[i] = integerArray[i] + 1;
        }
    }

    public static void main(String[] args) {
        int[] numbers = {1, 2, 3};

        addOne(numbers);

        System.out.println(Arrays.toString(numbers)); // [2, 3, 4]
    }
}
```

It is important to distinguish between **modifying the array** and **reassigning the parameter**.

For example:

```java
public static void replaceArray(int[] array) {
    array = new int[]{10, 20, 30};
}

public static void main(String[] args) {
    int[] numbers = {1, 2, 3};

    replaceArray(numbers);

    System.out.println(Arrays.toString(numbers)); // [1, 2, 3]
}
```

The parameter `array` receives a copy of the reference. Reassigning that local reference does not change the reference stored in `numbers`.

## Array Utilities

### `java.util.Arrays`

`java.util.Arrays` contains various static methods for manipulating and inspecting arrays, such as **sorting, searching, filling, comparing, printing, and converting arrays to lists**.

Some commonly used methods are:

* `copyOf()` / `copyOfRange()`
* `fill()`
* `equals()` / `deepEquals()`
* `sort()`
* `binarySearch()`
* `toString()` / `deepToString()`
* `asList()`

For example:

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] numbers = {5, 2, 8, 1, 3};

        Arrays.sort(numbers);

        System.out.println(Arrays.toString(numbers));
    }
}
```

The output is:

```text
[1, 2, 3, 5, 8]
```

For multidimensional arrays, `toString()` only describes the nested array references. `deepToString()` should be used to print nested arrays:

```java
int[][] matrix = {
    {1, 2},
    {3, 4}
};

System.out.println(Arrays.deepToString(matrix));
```

The output is:

```text
[[1, 2], [3, 4]]
```

`Arrays.asList()` can be used to obtain a fixed-size `List` backed by an array of reference types.

```java
String[] names = {"Alice", "Bob", "Carol"};

List<String> list = Arrays.asList(names);
```

> **NOTE:** `Arrays.asList()` does not behave the same way with primitive arrays. For example, passing an `int[]` produces a list containing the `int[]` as a single element rather than a list of individual `Integer` values.

### `System.arraycopy()`

`System.arraycopy()` copies elements from one array to another, starting at a specified position in the source array and placing them at a specified position in the destination array.

The method has the following form:

```java
System.arraycopy(
    sourceArray,
    sourcePosition,
    destinationArray,
    destinationPosition,
    length
);
```

It provides an efficient and convenient way to copy a range of array elements without writing the copy loop manually.

```java
import java.util.Arrays;

public static void main(String[] args) {
    int[] v1 = new int[8];
    int[] v2 = new int[8];

    Arrays.fill(v1, 10);
    Arrays.fill(v2, 12);

    // manual array copy
    for (int i = 0; i < 4; i++) {
        v2[i + 4] = v1[i];
    }

    // system array copy
    // produces the same result as the manual version
    // System.arraycopy(v1, 0, v2, 4, 4);

    System.out.println(Arrays.toString(v1));
    // [10, 10, 10, 10, 10, 10, 10, 10]

    System.out.println(Arrays.toString(v2));
    // [12, 12, 12, 12, 10, 10, 10, 10]
}
```

The call:

```java
System.arraycopy(v1, 0, v2, 4, 4);
```

means:

* copy `4` elements
* from `v1`
* starting at index `0`
* into `v2`
* starting at index `4`

The resulting contents of `v2` are:

```text
[12, 12, 12, 12, 10, 10, 10, 10]
```
