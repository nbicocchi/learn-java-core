# E2.2 — Java Control Flow

## Code blocks and scope

Braces `{ }` delimit blocks. A local variable is available only within its scope and must be definitely assigned before use.

```java
public class ScopeDemo {
    public static void main(String[] args) {
        int number = 3;
        {
            int doubled = 2 * number;
            System.out.println(doubled); // 6
        }
        System.out.println(number); // 3
        // System.out.println(doubled); // Does not compile: out of scope
    }
}
```

```java
int count;
// System.out.println(count); // Does not compile: not initialized
count = 3;
System.out.println(count);
```

Fields receive default values; local variables do not receive the same automatic initialization. Keep variables close to where they are needed.

## Flow-control statements

### Decision statements

#### if statement

Only the first matching branch is executed:

```java
int time = 22;
if (time < 10) {
    System.out.println("Good morning.");
} else if (time < 20) {
    System.out.println("Good day.");
} else {
    System.out.println("Good evening.");
}
```

**Check boundaries:** which branch runs for `9`, `10`, `19`, and `20`? What policy should apply to an invalid hour such as `-1`?

#### Modern switch statement

Use arrow labels when selecting an action without fall-through:

```java
char grade = 'B';
switch (grade) {
    case 'A' -> System.out.println("Excellent!");
    case 'B', 'C' -> System.out.println("Well done");
    case 'D' -> System.out.println("Danger zone");
    default -> System.out.println("Invalid grade");
}
```

An arrow branch does not fall through into the next branch, so no `break` is required.

#### Switch expression

When selecting a value, use a switch expression:

```java
char grade = 'B';
String message = switch (grade) {
    case 'A' -> "Excellent!";
    case 'B', 'C' -> "Well done";
    case 'D' -> "Danger zone";
    default -> "Invalid grade";
};
System.out.println(message);
```

A switch expression must be exhaustive. A block branch uses `yield` to supply its value. Pattern matching in switch is a later topic.

#### Classic switch statement

**Reference — reading existing code.** You will also encounter the older colon form:

```java
switch (grade) {
    case 'A':
        System.out.println("Excellent!");
        break;
    case 'B':
    case 'C':
        System.out.println("Well done");
        break;
    default:
        System.out.println("Check your grade");
}
```

Execution can fall through unless interrupted by `break` or another transfer of control. Be able to read this form; prefer the arrow form when fall-through is not intended.

### Iterative statements

#### while statement

The condition is checked **before** the body, which may run zero times:

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
```

#### do-while statement

The condition is checked **after** the body, which runs at least once:

```java
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 5);
```

**Predict:** how do these two examples differ if `i` starts at `5`?

#### for statement

A `for` loop groups initialization, condition, and update:

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i); // 0, 1, 2, 3, 4
}
```

The update runs after the body, before the next condition check. Ask how the loop makes progress and why it eventually terminates.

**Review:** an assistant changes `< 5` to `<= 5`. How many iterations run now? Is the extra iteration intended?

#### Enhanced for statement

Use enhanced `for` to visit elements of an array or an `Iterable`:

```java
String[] cars = {"Supra", "Lancer Evo", "Impreza"};
for (String car : cars) {
    System.out.println(car);
}
```

Arrays are developed in E2.4. This loop does not expose an index; choose a conventional `for` when the position is needed.

#### break and continue

* `break` exits the nearest enclosing loop or switch statement.
* `continue` starts the next iteration of the nearest enclosing loop. In a conventional `for`, its update expression still executes.

```java
for (int i = 0; i < 10; i++) {
    if (i == 4) {
        break;
    }
    System.out.println(i);
} // Prints 0, 1, 2, 3
```

```java
for (int i = 0; i < 10; i++) {
    if (i == 4) {
        continue;
    }
    System.out.println(i);
} // Prints 0, 1, 2, 3, 5, 6, 7, 8, 9
```

Be careful with `continue` in a `while`: skipping the statement that updates the loop variable can prevent termination.
